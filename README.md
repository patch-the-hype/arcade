# Patch's Arcade

35 AI-made games. Each built from one prompt, one HTML file, zero dependencies,
by a different AI model — then machine-judged. Unedited model output.

- `index.html` + `arcade.css` + `arcade.js` — arcade front (Team Open vs Team Closed)
- `play.html` + `play.js` — play shell wrapping each game
- `games/<slug>.html` — original, untouched model artifacts
- `thumbs/<slug>.png` — real gameplay captures
- `games.json` — metadata (model, team, wall-time, judge points)

Fonts: Press Start 2P, Inter (both SIL OFL — see fonts/).
